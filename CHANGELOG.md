# Changelog

## Sprint 12

Tenancy (org/workspace + Owner/Admin/Member/Read-only), Free/Pro/Team billing
meters with a Stripe webhook stub, expiring recruiter share links, match
thumbs-up training, AB explanation styles, HTML sanitizer, Google SSO scaffold,
fr/es locales, dark/light theme, cookie banner, Help/Changelog/Legal/Admin
routes, public API keys, CSP + rate-limit headers, operator CLI, and local
bootstrap. Optional adapters stay off. See `docs/ops/sprint12.md`.

## Sprint 9

Matching now returns calibrated fit buckets, must-have skill gates, location /
seniority / visa boosts, and up to five evidence sentences per job. The Job Feed
filters on salary, seniority, and keywords, highlights evidence in “Why this
score”, and supports bulk-select apply (one consenting Apply modal at a time).
Email classifies interview / rejection / follow-up mail, adds recruiter
templates, and recommends reply windows. Indeed/LinkedIn adapters are fixture-only
behind flags and robots/consent gates — no HTML scraping. IMAP stays a Graph-only
health stub. Operator flags, retention planner, attachment policy, cover letters
from match explanations, taxonomy/reindex CLIs, and Sprint 9 tests ship with this
batch.

See `docs/ops/sprint9-migration.md`.
