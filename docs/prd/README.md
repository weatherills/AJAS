# AJAS Product Requirements (PRDs)

One consolidated PRD document per feature. Each combines the backend, database,
and frontend requirements for that feature into a single page. The canonical,
CodeSpring-generated sources live under
[`.codespring/PRDs/`](../../.codespring/PRDs/) and remain the source of truth;
the documents here are a convenience view organized one-per-feature and ordered
by the runbook phases in
[`.codespring/CURSOR_RUNBOOK.md`](../../.codespring/CURSOR_RUNBOOK.md).

| Phase | Feature | Consolidated PRD |

| 2 | Auto-Apply | [auto-apply.md](./auto-apply.md) |
| 3 | Settings | [settings.md](./settings.md) |
| 4 | Resume Management | [resume-management.md](./resume-management.md) |
| 5 | Job Source Integration | [job-source-integration.md](./job-source-integration.md) |
| 6 | Matching & Ranking | [matching-ranking.md](./matching-ranking.md) |
| 7 | Email Ingestion & Reply | [email-ingestion-reply.md](./email-ingestion-reply.md) |
| 8 | Learning Loop | [learning-loop.md](./learning-loop.md) |

Each feature's source PRDs (backend / database / frontend) are linked at the top
of its consolidated document.
